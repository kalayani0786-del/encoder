# 4-to-2 Encoder using Verilog

## Overview

This project implements and simulates a **4-to-2 Encoder** using Verilog HDL.

An encoder is a combinational digital circuit that converts one active input into a binary code at its output.

This project contains:

* 4 input lines: `I[3:0]`
* 2 output lines: `Y[1:0]`
* 1 valid output: `Valid`

The encoder assumes that only one input is HIGH at a time.

## Encoding Operation

```text
I0 → 00
I1 → 01
I2 → 10
I3 → 11
```

## Simulation

This project can be simulated using **Icarus Verilog** and **GTKWave**.

### Step 1: Compile

```bash
iverilog -o encoder_sim encoder_4to2.v tb_encoder_4to2.v
```

### Step 2: Run

```bash
vvp encoder_sim
```

The testbench generates:

```text
waveform.vcd
```

### Step 3: View Waveform

```bash
gtkwave waveform.vcd
```

Add the following signals:

```text
I
Y
Valid
```

## Expected Output

```text
 I     | Y  | Valid
-------------------
0000 | 00 |   0
0001 | 00 |   1
0010 | 01 |   1
0100 | 10 |   1
1000 | 11 |   1
0011 | 00 |   0
```

The `0011` case is invalid because more than one input is HIGH.
